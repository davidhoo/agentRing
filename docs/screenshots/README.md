# Screenshots for README

Put real product shots here, then link them from `README.md` / `README_EN.md`.

Suggested filenames:

- `menubar-popover.png` — menu bar popover with usage rings
- `settings-general.png` — General settings
- `settings-auth.png` — Auth settings (segmented providers)

Capture tips:

1. Run a Release or Debug build locally.
2. Use macOS Screenshot (`Cmd+Shift+4`, then Space for window) on the popover / settings window.
3. Prefer light appearance for the first hero shot; keep resolution crisp (2x Retina is fine).
4. Do not commit secrets, tokens, or personal emails visible in shots — redact first.

Until real shots exist, the README uses the app icon as a temporary visual.
